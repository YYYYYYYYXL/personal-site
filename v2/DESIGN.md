# 个人网站 V2：设计与工程规范

## 定位

于鑫磊的长期个人主页与技术作品集。表达数据、模型、应用开发和工程实践的交集，用项目和具体工作说明能力。2027 届、本科在读；不使用精通标签、技能百分比和没有证据的成果指标。

## 视觉

- 基底 `#03070c`，次级表面 `#07101b`，正文 `#e9eff8`，辅助文字 `#a5b4ca`，强调 `#2aa3ff`。
- 标题采用霞鹜文楷的本站字形子集 Xinlei WenKai（500），正文、导航与标签采用 Noto Sans SC 可变字体。全部本地托管，正文按 unicode-range 加载；标题优先预加载，缺失字符回退到正文字体。不显示装饰性英文眉题、分区编号、项目计数和插画角标。
- 黑蓝深夜工作室插画作为氛围素材，与大标题形成非对称叠层。人物不能进入正文的阅读区域。
- 内容宽度上限 1200px；桌面侧边距 48px，窄屏 20px；圆角 16–24px；使用细分隔线和实色表面，避免发光边框。
- 首页“能力与实践”使用三张接近正方形的配图卡，依次展示服务器部署、Linux、计算机网络，不显示原项目区辅助句。项目列表保留项目配图卡：上方项目相关视觉，下方标题、简介、技术栈与详情箭头；不显示分类、状态或编号。两类卡片均采用桌面三列、中等屏幕两列、手机单列。项目列表保留搜索。详情页使用正文与目录布局；关于页使用个人摘要、经历和实践分组。
- 按钮、链接、标签、导航、页脚共享组件。Astro ClientRouter 提供 180–320ms 页面切换，导航与页脚保持稳定；下方内容滚动入场约 480ms，筛选结果淡入 240ms。交互脚本每次导航清理并重新绑定，避免重复监听。遵循 `prefers-reduced-motion`，无 JS 时全部内容可见。

## 目录与路由

```text
v2/
  src/assets/            插画、头像；由 Astro 构建优化
  src/components/        导航、页脚、图标、按钮、项目卡、联系区
  src/content/projects/  Markdown 项目内容，集合 schema 校验
  src/data/              公开个人信息、关注方向、技术实践
  src/layouts/           统一 SEO 与页面骨架
  src/pages/             首页、项目列表、详情、关于、联系、404、sitemap
  src/styles/            设计变量与响应式样式
  public/                favicon 与 robots
```

路由：`/`、`/projects/`、`/projects/<id>/`、`/about/`、`/contact/`、`/404.html`。联系内容位于独立页面，导航、关于页按钮和页脚入口统一指向 `/contact/`。

## 内容依据

- 背景：根目录 USER_CONTEXT.md，仅作为私有编辑依据，不复制到 public 或 dist。
- 商品分析：只读核对 `taobao-shop-info-analysis` 的 README、清洗函数、Django API、Vue 页面与依赖；不运行或修改该项目。数据来源为已有 CSV，不宣称实现在线爬取或使用实时数据。
- 毕设：仅展示背景文件明确的研究内容；标记进行中。BM3D 为无需训练的基线方法。不把历史指标当成最终实验结果。
- Magic Resume：第三方开源应用的适配、部署和交付实践，明确贡献边界。
- 页面插画均为视觉概念；不充当系统截图或实验成果。未核实的成果不补造。
- 公开联系方式采用旧站已有公开邮箱与 GitHub，不公开基础设施管理信息。

## 生产部署边界

旧站 HTML 与静态资源继续保留在仓库，V2 源码独立维护。现有 GitHub Actions 工作流已适配 Astro 构建，只上传 `v2/dist/`；保留 SSH/rsync 与站点备份，不注册或发布 Sites。

部署脚本只替换个人站静态目录，保留证书验证文件；发布后检查 HTTPS 和内容路由，失败自动恢复备份。不得上传仓库根目录、node_modules、源码或 USER_CONTEXT.md，不改动其他应用及共享 Nginx、DNS 配置。
